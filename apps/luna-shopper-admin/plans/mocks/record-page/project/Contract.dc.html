A record page is drawn from the descriptor of its resource and from nothing else. New marks what the descriptor does not have today. The rest is ResourceDescriptor as it is in dev.

Every field can state

label, helpThe words beside the field and the line under its control.
requiredA star, and a refusal when it is empty.
nullableEmpty is a normal answer. It reads None, and a picker offers None first.
editableYes, no, 'create' (set once, then locked) or 'edit' (not drawn on a new record).
setBy NewThe words beside a value that cannot be changed, such as "Set by the harvester".
check NewAn amber state beside the value when a person must look at it, such as a guessed postal code.

The record block of a brand New

record: {
  sections: [
    { title: 'brands.section.name',
      fields: ['label', 'key'] },
    { title: 'brands.section.links',
      fields: ['canonicalBrandId',
               'privateLabelSupermarketId'] },
  ],
  children: [
    { resource: 'brands', by: 'canonicalBrandId',
      as: 'panel', rows: 5 },
    { resource: 'items', by: 'brandId', as: 'link' },
  ],
  facts: { added: 'createdAt', changed: 'updatedAt',
           also: [] },
  afterAdd: 'open',
}

What each line decides

sectionsThe order of the page. A section with no field in this mode is not drawn. With no record block, every field is one section in the order of fields.
childrentab is a tab beside Details. panel is a short list in the page. link is a count that opens the filtered list.
factsThe Record block. The ID is always in it. also adds fields such as the source of a row.
afterAddopen the new record, or go back to the list.

What the page reads that is there today

title is the heading. rowStates are the states beside it. info is the info button. caution is the line above the first section of a form. parent is the back link and a locked field on a new record. actions.named is the More menu, and danger: true New puts an action under the line in red. errorFields and errorLinks place a refusal.
