Plan 0045. PICK UP WHERE YOU LEFT OFF is removed, not restyled: it answered what was I doing with device-local guesswork, and the shopping list card answers it with server truth, the ACTIVE generated list. With no active list the section is absent entirely: no header, no empty card, no gap.

0019 section 4's Get shopping list button ships enabled at last; the sheet behind it is what it was waiting for.

THE SHEET'S THREE INPUTS. Name, empty: an unnamed list shows its generation date, and a second one the same day gets a number appended. Profile, one row naming the default shopping profile (0049), absent when the user has exactly one. Sources: a checkbox tree of zones and lists, prechecked from the profile's stored generation scope, showing only lists where the caller holds WRITE (backend 0051 section 2).

A zone checked whole means every writable list in it, including ones created later, which is what ALL stores. Submitting is idempotent and lands in the new basket (0044's screen).

THE HISTORY CANNOT LOSE ENTRIES. Newest first, cursor paginated, active runs marked and sorted on top. There is no delete and no archive control anywhere on the page: the API keeps deletion (backend 0050 section 7) and no screen offers it for now, deliberately. That is the point of keeping a history.
