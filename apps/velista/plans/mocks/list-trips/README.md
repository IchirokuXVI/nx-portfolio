# The zone list grouped by trip

The mock for `0088` and `0089`, with backend `0122` and `0123` behind them.

**This folder is not built by `build-index.mjs`.** Every other folder here is a canvas of
still artboards. This page is one working screen, because what it has to show is motion and
state: a group that folds, a suggestion that moves into the list, a list with a live basket
and the same list without one. So `index.html` is written by hand, it is the file that is
published, and there is no `canvas.json` and no artboard beside it.

What it follows from the other folders: literal colours taken from `0002`, both themes, a
phone column, and "group" in the UI where the code says zone.

The right hand column states the rules the screen follows, what loads and when, and what
was left for later. Those three lists are a summary. The plans are the authority.
