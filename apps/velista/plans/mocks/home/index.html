Home page, plan 0003.

Phone only, 390x844. No desktop design is planned.

The home route IS the landing page: anonymous visitors get the front door, signed in users get their groups.

Top row is the Night theme. Bottom row covers empty, no connection and error.

Named Velista: the person sailing the velero.

The mark is a small sailboat whose one oversized sail is a sheet of paper with scribbled lines. The sail IS the shopping list, which is what carries you along.

See the brand artboard on the right for the size tests.

DECIDED: the UI says "group" in English and "grupo" in Spanish. The CODE keeps saying zone, everywhere: the API, the enums, the routes, the contracts and even the translation KEYS are unchanged.

So group is purely a translation value. Never rename a zone symbol in code to match the UI word.

TEMPORARY connection handling, by decision.

No offline queue, no background sync, no service worker. Losing the network shows one blocking screen, and the page reloads itself when the connection returns.

This is knowingly weak for a shopping list used in a supermarket. It is a placeholder until the PWA work lands, not the final answer.

The join request row names the FIRST requester, then adds "and X more want to join" only when there is more than one. The Home card shows the multi case; with a single request it reads "Ines wants to join".
