# Velista terms acceptance mock sources

The design for `../../0173-a-person-accepts-the-terms-when-an-account-is-made.md`: the one
form for register and upgrade, the line under every Google button, the guest notice on the
three entry screens, the prompt that stands in place of the page, the documents as a sheet,
and a version that changed while the page was open.

How these folders work, how to rebuild `index.html`, and the conventions every artboard
follows are in **`../README.md`**. Read that first.

| File                       | Artboard                                                                                      |
| -------------------------- | --------------------------------------------------------------------------------------------- |
| `AccountForm.dc.html`      | Register with the box ticked, register pressed with the box clear, and upgrade                |
| `GoogleLine.dc.html`       | The front door and sign in, each with the line under the Google button                        |
| `GuestNotice.dc.html`      | Create a group, join with a code and the shared link, the notice above the button (A, chosen) |
| `GuestNoticeAfter.dc.html` | The notice under the button (B, not chosen)                                                   |
| `Prompt.dc.html`           | The prompt with no version accepted, with an older one accepted, and after a failed accept    |
| `TermsSheet.dc.html`       | The terms as a sheet over register                                                            |
| `Stale.dc.html`            | A stale version on register, on Google at sign in, and on create                              |
