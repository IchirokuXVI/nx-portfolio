THE RULES · what is pointed at, and how it ends
A STOP WITH NOTHING TO POINT AT IS NOT SHOWN
Talking to a list is a sixth stop, and a new account has no list to talk to.
So it is left out on the first run and appears when the tour is played again later, by which time there is a list and a microphone to point at. The tour counts its stops when it starts, which is why the cards can say 1 of 5 and mean it.

SKIPPING · on every card, and it means the same as finishing
Skip the tour Same size and same place on all five cards, never a small cross in a corner.
Skipping ends the tour and does not ask again. It is not a loss: the row below plays the whole thing whenever somebody wants it.
